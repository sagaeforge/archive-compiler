# NCX 프로젝트
NCX 프로젝트는 Nugunga Compiler eXtentions의 약자로 컴파일러 확장 프로젝트임. <br>
프론트엔드의 교체를 통해 다양한 프로그래밍 언어를 지원하는 CC 프로젝트임.

<br><br>
## NCX 하위 프로젝트
<hr>
NCX 하위 프로젝트는 크게 3가지 파트로 분리가 되어 있음.

    * nCX: 공용 라이브러리
        * nGC: 가비지 컬렉션
        * nString: 문자열 라이브러리
    * nCompiler: 컴파일러
    * nVM: 가상 머신

<br><br>

## 컴파일러의 구성
<hr>
nCompiler의 요구 사양은 4-Pass를 적용해 최적화를 진행할것임. <br><br>

전처리기에서 예약어를 최적화 및 const 키워드를 최적화를 진행함. 특정 파일을 캐시를 함으로써 전반적인 프로그램 효율을 높임. <br>
프론트엔드에서 AST를 최적화하고 의사를 최적화함. <br>
중간코드 생성기에서 AST를 기반으로 명령어를 만들어냄. 여기서 바로 실행이 가능하며, 중간코드 최적화를 거침. <br>
목적코드 생성기에서 중간코드 IR를 기반으로 실제 목적코드를 생성하고 최적화를 진행함. <br>
