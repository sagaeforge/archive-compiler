# NCC 프로젝트
nugunga Compiler Chain의 약자로, 컴파일러와 가상머신을 만드는 프로젝트입니다.

## 폴더 구조
* lib - 외부 라이브러리
* src - 코드의 목적에 따라서 관리함.
  - lib - 공유하는 라이브러리들
  - n-cc - 컴파일러
  - n-vm - 가상머신
  - n-asm - 어셈블러
* test - 테스트 코드

# 확장자
.ns - 소스 파일
.nbc - 컴파일된 바이트 코드 파일


# 목표
NCC는 프로그램으로 출력하는 것이 목표가 아님. 런타임에서 프로그램이 동적으로 만들어지고, 클러스터링을 통해 IoT를 실현하는 것이 목표임.

결국 라이브러리 형태로 사용할 수 있도록 개발이 되어야 함.
